===============================================================
 ГОЛОСОВОЙ AI-АССИСТЕНТ ЗАДАЧ И ВСТРЕЧ — КАК ВСЁ СОБРАТЬ ВОЕДИНО
===============================================================

Что это: веб-приложение. Вы говорите или пишете запрос в свободной
форме («Напомни завтра в 10 позвонить Ивану»), ИИ (Gemini) понимает
его, сохраняет в базу, а ответ приходит текстом и голосом.


---------------------------------------------------------------

---------------------------------------------------------------
2. ЧТО НУЖНО ЗАРАНЕЕ
---------------------------------------------------------------

 - Python 3.11 или новее   (проверка: python3 --version)
 - Ключ Gemini API         (бесплатно: https://aistudio.google.com)
 - Современный браузер (Chrome, Edge, Firefox) для микрофона


---------------------------------------------------------------
3. ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ
---------------------------------------------------------------

Шаг 1. Распакуйте архив и откройте терминал в папке проекта:

    cd voice-assistant-tasks

Шаг 2. Создайте виртуальное окружение и включите его:

    Linux / macOS:
        python3 -m venv venv
        source venv/bin/activate

    Windows (PowerShell):
        python -m venv venv
        venv\Scripts\Activate.ps1

Шаг 3. Установите пакеты:

    pip install -r requirements.txt

Шаг 4. Создайте файл настроек и впишите ключ:

    Linux / macOS:   cp .env.example .env
    Windows:         copy .env.example .env

    Откройте .env и замените значение:
        GEMINI_API_KEY=ваш_настоящий_ключ

    По желанию добавьте свой часовой пояс (запасной вариант,
    браузер обычно передаёт его сам):
        DEFAULT_TIMEZONE=Europe/Chisinau

Шаг 5. Запустите сервер:

    uvicorn app.main:app --reload --port 8000

Шаг 6. Откройте в браузере:

    http://localhost:8000

    Микрофон работает на localhost и на сайтах с HTTPS.
    Браузер спросит разрешение на микрофон — разрешите.


---------------------------------------------------------------
4. ПРОВЕРКА, ЧТО ВСЁ РАБОТАЕТ
---------------------------------------------------------------

Проверка сервера:   http://localhost:8000/api/health
                    должно вернуть {"status":"ok"}

Нажмите кнопки-примеры над чатом или скажите:

  1. «Напомни мне завтра в 10 утра позвонить Ивану»
        -> запись типа «Напоминание» появилась справа
  2. «Добавь встречу с командой завтра в 15:00»
        -> запись типа «Встреча»
  3. «Поставь встречу с дизайнером завтра»
        -> ассистент спросит, на какое время
  4. «Добавь ещё встречу завтра в 15:30»
        -> ассистент предупредит о пересечении
  5. «Что запланировано на эту неделю?»
        -> ассистент перечислит записи
  6. «Найди всё про Ивана»
        -> найдёт напоминание про звонок
  7. «Перенеси её на послезавтра в 16:00»
        -> поймёт, что «её» — последняя упомянутая запись
  8. «Отметь выполненной»

В правой панели можно также вручную отметить запись выполненной (✓),
удалить (✕) и отфильтровать по типу и статусу.

---------------------------------------------------------------
6. ДЕПЛОЙ В ИНТЕРНЕТ (RENDER, БЕСПЛАТНО)
---------------------------------------------------------------

 1. Загрузите папку проекта в репозиторий на GitHub.
    ВАЖНО: файл .env в репозиторий не попадает (он в .gitignore),
    ключ вписывается только на сайте Render.
 2. На https://render.com: New -> Web Service -> выберите репозиторий.
 3. Render найдёт Dockerfile сам.
 4. В разделе Environment добавьте переменные:
        GEMINI_API_KEY      ваш ключ
        DEFAULT_TIMEZONE    например Europe/Chisinau
 5. Create Web Service. Через пару минут появится адрес вида
    https://имя.onrender.com — он работает по HTTPS, микрофон тоже.

 Внимание: на бесплатном тарифе файл базы tasks.db стирается при
 перезапуске сервиса. Перед показом жюри создайте записи заново
 или подключите постоянный диск / внешнюю базу данных.
 Первый запрос после простоя может идти около минуты.


---------------------------------------------------------------
7. ЧАСТЫЕ ПРОБЛЕМЫ
---------------------------------------------------------------

«Не настроен GEMINI_API_KEY»
    Нет файла .env или ключ не вписан. Перезапустите сервер после
    правки .env.

«Лимит запросов к Gemini исчерпан»
    Бесплатная квота. Подождите минуту или смените модель:
    MODEL_NAME=gemini-3.5-flash-lite  (в .env)

Не работает микрофон
    Откройте сайт через http://localhost:8000 или по HTTPS и
    разрешите доступ к микрофону в настройках браузера.

Нет голосового ответа
    Озвучка использует интернет-сервис Edge TTS. Без интернета
    ответ придёт только текстом. Проверьте флажок «Озвучивать
    ответы» в шапке.

Время сдвинуто на несколько часов
    Откройте сайт в браузере (он передаёт часовой пояс сам) либо
    задайте DEFAULT_TIMEZONE в .env.

Ошибка модели (404 / model not found)
    Google мог переименовать модель. Укажите актуальные имена в .env:
        MODEL_NAME=...
        EMBEDDING_MODEL=...


---------------------------------------------------------------
8. ВСЕ НАСТРОЙКИ (.env)
---------------------------------------------------------------

 GEMINI_API_KEY     ключ Gemini API (обязательно)
 DATABASE_PATH      путь к файлу базы, по умолчанию tasks.db
 MODEL_NAME         модель, по умолчанию gemini-3.5-flash
 EMBEDDING_MODEL    модель для поиска по смыслу,
                    по умолчанию gemini-embedding-001
 THINKING_LEVEL     глубина размышления модели: minimal, low, medium,
                    high; по умолчанию low (быстрее). Пусто — как
                    задумано моделью
 TTS_VOICE          голос озвучки, по умолчанию ru-RU-SvetlanaNeural
                    (мужской: ru-RU-DmitryNeural)
 DEFAULT_TIMEZONE   запасной часовой пояс, по умолчанию UTC


---------------------------------------------------------------
9. КАК ЭТО УСТРОЕНО (КОРОТКО, ДЛЯ ЗАЩИТЫ)
---------------------------------------------------------------

 Голос -> браузер записывает аудио -> /api/voice
       -> Gemini переводит речь в текст
       -> агент (Gemini + Function Calling) выбирает действие:
          создать / показать расписание / найти / изменить / удалить
       -> действие выполняется в SQLite
       -> текст ответа озвучивается (Edge TTS) и возвращается
          вместе с обновлённым списком записей.

 - Текущее время пользователя вставляется в каждый запрос,
   поэтому «завтра» и «в пятницу» считаются верно.
 - Поиск гибридный: точное совпадение слов + векторное сходство.
 - История диалога хранится на сервере по session_id, поэтому
   работают уточнения вроде «перенеси её».
 - Ошибки Gemini (лимит, ключ, сеть) превращаются в понятную фразу.


---------------------------------------------------------------
10. ДАЛЬШЕ МОЖНО УЛУЧШИТЬ
---------------------------------------------------------------

 - Постоянная база (PostgreSQL + pgvector) вместо SQLite
 - Фоновые напоминания, срабатывающие в нужное время
 - Синхронизация с Google Calendar
 - Повторяющиеся события
 - Вход по логину и отдельные данные для каждого пользователя
